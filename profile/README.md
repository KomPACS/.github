# KomPACS

**No exam without a comparison.**

Before a CT, MRI, PET or tumor board, KomPACS finds the relevant prior exams, checks them in PACS and requests what is missing.

**1st place, [Rakathon 2026](https://www.rakathon.cz/)** (FN Motol, Nemocnice Na Homolce, InterSystems IRIS for Health).
